# Calculator 🔢✨

A modern neumorphic calculator built with HTML, CSS & JavaScript. Features a clean soft UI with smooth animations and responsive design

### ✨ Features
- **Neumorphic Design** - Soft UI with dual-shadow effects
- **Smooth Animations** - Buttons elevate on hover & press inward on click
- **Basic Operations** - Addition, Subtraction, Multiplication, Division, Percentage
- **Responsive** - Works perfectly on mobile, tablet & desktop
- **Error Handling** - Prevents invalid expressions like `5++2`
- **Clear & Delete** - `C` to reset, `⌫` to remove last digit
- **Gradient Theme** - Modern purple gradient background

### 🛠️ Built With
- **HTML5** - Semantic structure
- **CSS3** - Flexbox, Neumorphism, CSS Animations, Media Queries
- **JavaScript** - Event handling, DOM manipulation, Expression evaluation

### 💡 Key Learnings
1. Implementing neumorphism using `box-shadow` and `inset` shadows
2. DOM manipulation with `querySelector` and event listeners
3. Error handling in JavaScript using `try-catch` blocks
4. Responsive design with CSS Flexbox
